# موقع Bellezza Pharma

صفحة **"تواصل معنا"** الرسمية لشركة Bellezza Pharma لمستحضرات التجميل والمكملات الغذائية (EST 2015).

🌐 **الرابط:** https://bellezzapharma.github.io

## فيها إيه

- روابط السوشيال: فيسبوك، إنستجرام، تيك توك، إيميل
- أرقام التواصل (موبايل وأرضي)
- طرق الدفع والتحويل: فودافون كاش، وحساب CIB / إنستاباي
- الفروع: المقر الرئيسي بالجيزة، فرع الدلتا بطنطا، فرع الصعيد بسوهاج

## التعديل

الموقع كله ملف واحد: `index.html` (HTML + CSS جوه نفس الملف، خط Cairo من Google Fonts).
أي تعديل يتعمل له push على `main` بيظهر على الرابط خلال دقيقة أو اتنين عن طريق GitHub Pages.
ملف `.nojekyll` موجود عشان GitHub ينشر الملفات زي ما هي من غير Jekyll.

> ⚠️ الريبو ده **Public** — أي حد يقدر يشوف الكود. متحطش فيه أي باسورد أو بيانات داخلية.
